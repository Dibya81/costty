# ScrollCraft engine (untouched)

`scrollcraft.js` and `scrollcraft.css` are copied verbatim from
nateherkai/scroll-craft. Per the skill's own rule, the engine is never edited
per-project — it is themed with CSS tokens and driven with our own markup
(`data-sc-*` attributes) from `src/pages/Landing.tsx` and
`src/components/landing/*`.

If the upstream engine changes, re-copy both files wholesale rather than
patching them here.
